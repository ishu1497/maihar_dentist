Maihar City Dental Care website

Files:
- index.html: page content
- style.css: responsive styling
- script.js: mobile menu, year, WhatsApp appointment request

Preview:
Open index.html in a browser.

Publish free with GitHub Pages:
1. Create a GitHub repository (for example, maihar-city-dental-care).
2. Upload index.html, style.css, and script.js to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for the published site link to appear in Settings > Pages.

Before publishing:
- Confirm the phone number, address, opening hours and WhatsApp number with the clinic owner.
- Service cards are illustrative and should be edited to list only confirmed services.
- This is a static site; appointment requests are messages, not confirmed bookings.
